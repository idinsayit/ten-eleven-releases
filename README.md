# Ten Eleven

Ten Eleven for Android, by idinsayit.

The app is given out on the [Releases](https://github.com/idinsayit/ten-eleven-releases/releases) page of this repository. To install it, open that page on an Android phone, download the file ending in `.apk` from the newest release, and open it. The phone asks once whether it may install from your browser. It needs Android 8 or newer.

After that the app looks here for newer versions and offers them itself.

Every release is signed with the same key. The SHA-256 fingerprint of its certificate:
